# NS-5_continuity_05 — Keep source continuity through long Studio playback

[Task index](README.md) · [Task flow](../TASKFLOW.MD) · [North star](../MILESTONES.md#ns-5)

**Description:**

Connect the accepted optional exact-source-successor reconstruction to Studio's
bounded long playback session. The operator preferred this mechanism in one
20-second development comparison. Before this repair Studio rejected it for live
jobs and omitted its index when constructing that session. The shared session already
accepts the index; reuse it rather than invent another selector or renderer.

North star: NS-5. Outcome owner: WAV-04-CONTINUITY. Completion credit: 0 additional.
This is a runtime integration prerequisite for sustained listening, not a new
musical-quality claim. Full source/seed continuity, vocabulary and style gates
remain with [continuity_01](NS-5_continuity_01.md). The finite audition integration
and its actual browser gate remain [continuity_04](NS-5_continuity_04.md).

Execution status: AC1–4 mechanically qualified on 2026-10-27 by Big Boss with
bounded Spike/Spiegel assignments; AC5 actual browser acceptance remains open.
Criterion: preserve source-successor selection across long pulls.
Deliverable: explicit live control, shared native session and traceable excerpt.
Closing evidence: exact finite/live PCM prefix and replay, matching model/source
and policy identities, bounded resources, failure/cancel and actual consumer
checks. Stop on changed WFC tokens, silent retraining/fallback, source/range
mismatch, duration-dependent memory, false comparison lineage or a generic WFC
defect. No new recording, inference experiment, seed sweep or tuning policy.

**Acceptance Criteria:**

- AC1: Accept an explicit supported reconstruction policy for long playback,
  including 2-minute, 2-hour and 24-hour plans. Preflight declares its bounded
  index/work and retained-journal requirements. Unsupported or damaged inputs
  fail explicitly before audio, without a silent sparse fallback.
- AC2: Use the same primary index, selector and continuous WFC audio session as
  finite auditions. Retain model/training/source/range/seed identities and
  selection/overlap state across pulls. Reuse qualified completed journals with
  model reuse; complete verified preparation retained by a stopped session must
  not require hidden reanalysis. Bound memory/receipts independently of output
  duration. Keep sparse behavior unchanged.
- AC3: Expose the choice clearly in long playback. Retain reconstruction and
  policy in live status, final/partial results and saved excerpt evidence.
  Preserve the excerpt's actual session offset and source context. A later
  excerpt cannot be paired with an unrelated zero-offset finite baseline merely
  because seed, model and length happen to match. Saving feedback never trains.
- AC4: Meaningful checked native tests verify partition/prefix replay, cached
  journal reuse, explicit failure/cancel, source clocks and long plans. Actual
  pas2js consumer checks verify that the live choice reaches the job and state
  cleanup is preserved. Independent combined QA follows ready components.
- AC5: Exercise actual desktop/narrow playback, pause/stop and saved-excerpt
  navigation on isolated operator data; preserve user records and close owned
  browser/audio. Record unavailable browser evidence honestly and keep the task
  open until it passes. Sustained musical judgment remains continuity_01.
