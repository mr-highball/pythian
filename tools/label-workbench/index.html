Review history

Undo and redo apply to saved review events for the selected source. They never save automatically.

Keyboard: Ctrl/Cmd+Z stages undo, Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y stages redo. Left/right moves between source windows; up/down selects a label. Use Save review event to append every change.

Split or merge spans

Operations use exact half-open source frames. They are staged locally and never save automatically. A split withdraws the selected saved label and adds two labels. A merge accepts only adjacent or overlapping labels with matching identity on this source.

Split and merge edits stay in this browser until you explicitly save a review event.
